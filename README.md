# VY Glow

Приложение для macOS, которое управляет дешёвыми китайскими RGB LED-лентами по Bluetooth Low Energy. Живёт в строке меню рядом с Пунктом управления: кликнули по цветному кружку и выбрали цвет, без открытия окна.

Написано на Python (PySide6 + Bleak). Разработано и проверено на контроллере **BJ_LED_M** (в телефоне такие ленты управляются приложением MohuanLED) на MacBook Air M2.

## Возможности

- включение и выключение ленты;
- быстрые цвета и выбор любого цвета через системный диалог;
- яркость (программная, см. [Ограничения](#ограничения));
- таймер отключения: 15 мин, 30 мин, 1 ч, 2 ч или своё значение;
- эффекты (экспериментально);
- иконка в строке меню: кружок показывает текущий цвет ленты, серое кольцо означает, что лента выключена. Из меню можно управлять лентой, не открывая окно;
- тёмная минималистичная тема;
- сборка в обычное приложение `VY Glow.app`.

## Что понадобится

- Mac с Bluetooth (проверено на Apple Silicon, на Intel и старых версиях macOS не проверялось);
- Python 3.10 или новее. Разработка велась на 3.12;
- лента с контроллером семейства BJ_LED (приложение MohuanLED), включённая в USB или питание;
- 10 минут времени.

Проверьте, что Python установлен:

```bash
python3 --version
```

Если команды нет или версия ниже 3.10, поставьте Python с [python.org](https://www.python.org/downloads/) или через Homebrew: `brew install python@3.12`.

## Установка

### 1. Скачайте проект

```bash
git clone https://github.com/vladislav12-03/VY-Glow.git
cd VY-Glow
```

Нет `git`? Нажмите на странице репозитория Code → Download ZIP, распакуйте архив и откройте в Терминале получившуюся папку.

### 2. Создайте окружение и поставьте зависимости

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

После `source .venv/bin/activate` в начале строки терминала появится `(.venv)`. Это значит, что окружение активно. Активировать его нужно в каждом новом окне Терминала, где вы запускаете проект.

### 3. Найдите адрес своей ленты

Адрес ленты зашит в `main.py`, и он **у каждого свой**. Это идентификатор, который macOS выдаёт конкретному устройству на конкретном Mac, а не MAC-адрес. Чтобы найти свой, включите ленту, **закройте приложение MohuanLED на телефоне** (контроллер обычно принимает только одно подключение) и выполните:

```bash
python - <<'EOF'
import asyncio
from bleak import BleakScanner

async def main():
    found = await BleakScanner.discover(timeout=10)
    for d in found:
        if d.name:
            print(d.address, d.name)

asyncio.run(main())
EOF
```

В выводе найдите строку с именем `BJ_LED_M` (или похожим) и скопируйте адрес слева, он выглядит примерно так: `4FE2675F-A6FE-8861-15D2-18EC1C593597`.

Если ленты в списке нет: проверьте, что она включена, телефон не подключён к ней, и запустите поиск ещё раз.

### 4. Впишите адрес в `main.py`

Откройте `main.py` в любом редакторе и замените значение в начале файла:

```python
ADDRESS = "ВАШ-АДРЕС-ИЗ-ПРЕДЫДУЩЕГО-ШАГА"
UUID = "0000ee02-0000-1000-8000-00805f9b34fb"
```

`UUID` менять не нужно, у контроллеров этого семейства он обычно одинаковый.

## Первый запуск

```bash
python main.py
```

1. macOS спросит разрешение на Bluetooth для Терминала (или VS Code, если запускаете оттуда). Нажмите «Разрешить».
2. В окне приложения нажмите «Подключить». Статус сменится на зелёное «подключено».
3. Нажмите «Включить», затем любой цвет. Лента должна отреагировать.

Если лента не реагирует, раскройте внизу окна «Отладка»: там виден лог с отправленными байтами и ошибками.

## Сборка приложения VY Glow.app

Чтобы не запускать терминал каждый раз, соберите настоящее приложение:

```bash
chmod +x build_app.sh
./build_app.sh
```

Сборка занимает пару минут. В конце откроется папка `dist` с `VY Glow.app`:

1. Перетащите `VY Glow.app` в «Программы».
2. Запустите через Spotlight (Cmd+Пробел, затем «VY Glow») или из «Программ».
3. Разрешите доступ к Bluetooth, когда система спросит.

Что делает скрипт: собирает приложение через PyInstaller, добавляет в `Info.plist` описание для Bluetooth (без него macOS закрывает приложение при обращении к Bluetooth), скрывает иконку в Dock и подписывает приложение ad-hoc подписью.

Приложение подписано без сертификата разработчика. Если macOS при первом открытии ругается, нажмите на иконку правой кнопкой и выберите «Открыть». Адрес ленты вшивается в приложение при сборке, поэтому не забудьте вписать его в `main.py` **до** сборки.

## Как пользоваться

Кружок приложения появляется в строке меню. Нажмите на него:

| Пункт меню | Действие |
|---|---|
| Открыть VY Glow | показать окно |
| Включить / Выключить | питание ленты |
| Список цветов | быстрый выбор цвета |
| Выйти | закрыть приложение и отключить Bluetooth |

В окне есть:

- **Превью и быстрые цвета.** Выбранный цвет обведён белым кольцом.
- **Свой цвет.** Открывает системный диалог выбора цвета.
- **Яркость.** Меняет яркость текущего цвета.
- **Эффекты.** Кнопками ‹ › листайте режимы, «Запустить» применяет режим с указанным параметром. Смена цвета или яркости останавливает эффект.
- **Таймер отключения.** Выберите время и нажмите «Запустить». По истечении лента выключится.
- **Отладка.** Лог отправленных пакетов и поле для ручной отправки байтов.

Красная кнопка окна только прячет его, приложение остаётся в строке меню. Полностью закрыть можно пунктом «Выйти».

Хотите вернуть иконку в Dock? Удалите из `build_app.sh` строку с `LSUIElement` и пересоберите приложение.

## Обновление

```bash
cd VY-Glow
git pull
./build_app.sh
```

Закройте запущенную копию приложения перед пересборкой (пункт меню «Выйти») и замените её в «Программах» новой. Если вы правили адрес ленты в `main.py`, `git pull` может сообщить о конфликте: сохраните свой адрес, выполните `git stash`, `git pull`, `git stash pop`.

## Удаление

1. Выберите «Выйти» в меню приложения.
2. Удалите `VY Glow.app` из «Программ».
3. По желанию удалите запись VY Glow в «Системные настройки → Конфиденциальность и безопасность → Bluetooth» и саму папку проекта.

## Если что-то не работает

**Не подключается к ленте.**
Проверьте, что лента включена и приложение MohuanLED на телефоне закрыто (контроллер обычно держит одно соединение). Убедитесь, что в `main.py` стоит именно ваш адрес, а не чужой. Подойдите ближе: BLE работает на небольшом расстоянии.

**macOS не даёт доступ к Bluetooth или приложение сразу закрывается.**
Откройте «Системные настройки → Конфиденциальность и безопасность → Bluetooth». Если VY Glow или Терминал выключены, включите. Если после пересборки приложения доступ перестал работать, удалите запись VY Glow в этом списке и запустите приложение заново.

**При открытии `VY Glow.app` macOS пишет, что приложение повреждено или от неизвестного разработчика.**
Нажмите на иконку правой кнопкой и выберите «Открыть». Если приложение скачано из интернета и это не помогает, снимите карантин: `xattr -cr "/Applications/VY Glow.app"`.

**Иконки нет в строке меню.**
Если в строке меню много значков, на MacBook с вырезом часть может не поместиться. Закройте лишние значки или откройте окно через Spotlight.

**Статус «подключено», но лента молчит.**
Откройте «Отладка» и посмотрите лог: должна быть строка вида `-> ee02: 69 96 05 02 FF 00 00`. Если она есть, а лента не реагирует, попробуйте сначала нажать «Включить». Если лог показывает ошибку, пришлите её в Issues.

**Цвета на ленте не такие, как на экране.**
Это нормально для дешёвых лент: белые и пастельные оттенки часто уходят в голубой или розовый. Подбирайте цвет прямо на ленте.

**Сборка `build_app.sh` падает.**
Убедитесь, что установлен Python 3.10+ и есть интернет (скрипт скачивает PyInstaller). Пришлите последние строки вывода в Issues.

## Протокол

Команды отправляются в GATT-характеристику `ee02` (сервис `eea0`) без подтверждения (`write-without-response`).

| Действие | Пакет (hex) | Статус |
|---|---|---|
| Включить | `69 96 06 01 01` | работает на BJ_LED_M |
| Выключить | `69 96 02 01 00` | работает на BJ_LED_M |
| Цвет | `69 96 05 02 RR GG BB` | работает на BJ_LED_M |
| Эффект | `69 96 03 03 <режим> <параметр>` | экспериментально |

Формат пакетов восстановлен по экспериментам и описанию семейства контроллеров, это не официальная спецификация. У других ревизий контроллеров протокол может отличаться.

## Ограничения

- **Адрес ленты задаётся вручную** в `main.py` (см. [шаг 3](#3-найдите-адрес-своей-ленты)). Готовая сборка, сделанная на одном Mac, на другом работать не будет: у каждого компьютера свой идентификатор устройства.
- **Яркость** реализована программно: значения RGB умножаются на коэффициент `(яркость/100) ^ GAMMA`. Константа `GAMMA` в начале `main.py` задаёт кривую. Если ползунок кажется слишком тёмным внизу или слишком быстро доходит до максимума, подберите значение под свою ленту. Отдельной команды яркости в протоколе найти не удалось.
- **Эффекты** экспериментальные. Номера режимов (0–21) и смысл параметра (скорость?) подтверждены не полностью.
- Состояние ленты (включена или выключена) определить нельзя: контроллер не сообщает его обратно, приложение работает «вслепую».
- Проверено только на macOS и на одном контроллере.
