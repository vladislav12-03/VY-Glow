# VY Glow

Небольшой нативный GUI-прототип для macOS, управляющий Bluetooth LED-контроллером `BJ_LED_M`.

## Возможности первой версии

- выбор цвета через системный диалог macOS;
- применение цвета и быстрые цветовые пресеты;
- программная яркость (масштабирование RGB);
- включение и выключение;
- подключение к известному BLE ID.

## Требования

- macOS с Bluetooth;
- Python 3.10+;
- контроллер включён и находится рядом;
- закрыть MohuanLED на iPhone перед запуском, чтобы телефон не удерживал подключение.

## Установка и запуск

Открой Terminal и перейди в папку, куда распаковал архив:

```bash
cd /путь/к/VY-Glow
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python main.py
```

Если у тебя уже есть окружение `~/led-dev`, можно использовать его:

```bash
source ~/led-dev/bin/activate
python -m pip install -r requirements.txt
python main.py
```

## Важно

- BLE ID по умолчанию прописан в `main.py`: `4FE2675F-A6FE-8861-15D2-18EC1C593597`. Это идентификатор, который увидел Bleak на твоём Mac. Если macOS выдаёт другой ID после перезапуска/сброса Bluetooth, обнови `DEFAULT_ADDRESS`.
- UUID записи: `0000ee02-0000-1000-8000-00805f9b34fb`.
- RGB-пакет `69 96 05 02 R G B` подтверждён твоим тестом.
- Пакет включения `69 96 06 01 01` подтверждён твоим тестом.
- Пакет выключения `69 96 02 01 00` взят из исходников MohuanLED-Bluetooth_LED, но отдельно на твоём контроллере пока не проверен. Если выключение не сработает, сообщи об этом; цвет и включение проверены отдельно.
- Яркость регулируется программно: приложение умножает выбранные значения RGB на процент яркости.
- Приложение подключается к BLE на каждую команду и отключается после отправки. Это простой первый прототип, а не фоновая menu-bar app.
